# Wheel of Impossible Destiny
A playful, single-file spinning-wheel arcade app. Spin to discover one of twelve strange and funny outcomes, complete with neon visuals, sound effects, particle bursts, and a screen shake.
## How to use
1. Open `wheel-of-impossible-destiny.html` in a modern web browser.
2. Select **Spin the wheel** to reveal your destiny.
3. Use **Sound: on/off** to toggle audio.
The app has no installation steps or external dependencies. It respects the browser's reduced-motion preference.
## Built-in features
- Responsive dark-mode interface with a neon color palette
- Animated wheel with randomized outcomes
- Optional synthesized sound effects
- Particle burst and screen-shake effects after each spin
- Keyboard shortcut: press **Space** or **Enter** when the page itself is focused
- Live result announcement for assistive technologies
